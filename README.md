This repository contains the English and Turkish support and privacy pages for Orbimo, the underwater physics puzzle game by Aytuğ Berk Sezer. The site uses plain HTML with inline CSS and needs no build step. It is intended for GitHub Pages at https://aytzey.github.io/orbimo-site/ (App Store Support URL), with https://aytzey.github.io/orbimo-site/privacy.html as the Privacy Policy URL.
